Agent 文本交互
网站默认附带并自动载入 A/B/C 参数参考框架；在页面最上方的模型连接区域填写 API Key、选择服务商并获取/选择模型；同济用户勾选同济 AGI 并按需选择“记住Key”。Base URL 和模型名也在顶部设置区，可按服务商文档检查或手动修改，也可换载其他 Olorua JSON systems。框架中的模拟设定和待确认项不代表本岛实测，也不会把内置身体示例当成岛屿数据。JSON 中每个 system 成为一个岛屿 agent；网站另接入一个无预置参数的求生者 agent。
每次由你点“运行一轮”。同一轮所有 agent 并行读取相同起始状态和上一轮内容；本轮结束后，下一轮才互相看到本轮发言。网页保留完整对话，但发送给模型的上一轮历史最多 8000 字符，过长时只带最近内容。每次请求分别设置 1800 tokens（首段）或 1200 tokens（续写段）的输出上限；超长回答会持续分段续写，直到模型结束。每段原文先保存在本轮记录中，再拼成完整回答。续写请求和工具对话都不设固定轮数上限；左侧计数器累计记录工具对话轮次，悬停可查看各 Agent 数量。可选填一句任务，任务发送给全体；所有已载入 agent 每轮都会参与，不能单独关闭。任一 agent 失败，本轮状态都不提交，可重试同一轮。
agent 可以读取其他系统，但只能修改自己的参数、说明、事件队列和 time_clock 标注；每项状态变化都要求说明理由，并在聊天记录里显示修改前后。time_clock 标注不会推进岛屿模拟时钟。工具调用、逐次模型输出和错误收在可展开详情里。
页面底部并列显示行动点位地图与事件报告；每轮成功后依据输入、地图数据和 Agent 推理整理，结束并重置会话后清空本次标注与报告。
