Agent 文本交互
网站默认附带并自动载入 A/B/C 参数参考框架；展开右侧“参数观测与岛屿视图”配置模型服务，也可换载其他 Olorua JSON systems。框架中的模拟设定和待确认项不代表本岛实测，也不会把内置身体示例当成岛屿数据。JSON 中每个 system 成为一个岛屿 agent；网站另接入一个无预置参数的求生者 agent。
每次由你点“运行一轮”。同一轮所有 agent 并行读取相同起始状态和上一轮完整对话；本轮结束后，下一轮才互相看到本轮发言。可选填一句任务，任务发送给全体；所有已载入 agent 每轮都会参与，不能单独关闭。只要一个 agent 失败，本轮状态就不提交，可重试同一轮。
agent 可以读取其他系统，但只能修改自己的参数、说明、事件队列和 time_clock 标注；每项状态变化都要求说明理由，并在聊天记录里显示修改前后。time_clock 标注不会推进岛屿模拟时钟。工具调用和错误收在可展开详情里。
右侧观测栏包含旧地图、天气、资源和水量演示信息，当前为只读。这里的地图与模拟参数不是待载入的岛屿组 JSON，也不能当成 Olorua 实测值。
