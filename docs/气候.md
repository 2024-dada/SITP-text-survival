# 气候

## 大周期

以干湿季和逐月温雨作基础；为便于浏览分成四个大阶段：12—2月湿季盛期、3—5月湿转干过渡、6—8月干季阶段、9—11月干转湿过渡。阶段是演示分组，不意味着每个月均相同。斐济一般湿季11—4月、干季5—10月；Lakeba资料是区域参考，不是本岛实测。

## 小周期：小时天气

1. 日期从2027-05-01 09:00起；这是模拟本地时钟，不是当前真实日期。
2. 2027年沿用资料包合成雨日、雨窗和雨量。每小时雨量等于该日雨量除以配置雨窗长度；雨窗外为0。月雨量不能直接用作真实雨日概率。
3. 后续年份按种子把月内雨日循环平移-2至2天，年度雨量乘0.8至1.2的设计系数，不冒充年际气候预测。闰年2月29日复用28日参考，因此该月总量可能多出一天，不能声称仍严格匹配常年值。
4. 小时温度在参考高低温之间以14点为峰的余弦曲线变化。取高低温中点仅为模型曲线中线，不当作气象实测均温。
5. 云量在无雨时按四小时块生成0—0.7的种子序列；雨时取0.92。云量、风暴强弱描述均为模拟。当前没有风速、湿度的精细场。
6. 未来24小时卡片直接读取同一条时间序列，不会改变随机过程；预览天气不推进世界。

## 昼夜与太阳

太阳高度、方位按纬度、年内日序和本地近似太阳时估算；未校正均时差、经度与时区偏移，不能用于真实导航。太阳高度大于0视为白昼。阴雨、夜间及树冠遮挡时，不向角色提供确定方向。研究者的北箭头、方位标签和坐标是调试信息。

## 潮位

0.5米振幅、约12小时25分周期的余弦潮位，基准与相位均为设计。白天且潮位不高于0时开放演示岸边试采。没有真实潮表、风浪、盐度或安全航行判定。

## 天气传导

下雨→岩池及已启用集雨器进水→达到上限溢流；无雨→按温度参考系数损失。雨水同时使材料变湿、降低文字可辨距离。停雨后材料逐小时晾干。没有新增人体指标计算。
