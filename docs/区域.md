# 区域

版本：地图观测v1.0。对象：斐济Olorua。岛岸线来自OSM存档；38个子区域、植被分布与资源落点是模拟配置。

## 地图怎么读

地图使用本地米制坐标，原点为纬度-18.6054132、经度-178.75426615。E向东、N向北。观察位置取整到1米格，不代表1米级实测。区域边界是岸线与规则格交集，不是现场生态分界。四个老分区与38个观察子区属于不同层级；资源仍沿用原编号。

## 地形与视野

38个高程点来自约90米分辨率GLO90接口采样。程序用反距离平方加权插值，近岸35米作归零过渡；这是让海陆连续的设计，并非新增测量。林地假设9米冠层并以20米设计网格生成林隙、灌丛3米、岸缘1.5米，不对应树木逐株普查。水平视线每5米采样；有效范围内遇到比眼点高3米以上的地形与冠层时截断。远望仅描述大轮廓，不能得知后台精确库存。
