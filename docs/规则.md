# 规则

## 观察

研究者地图保留全图和库存。鼠标位置取整到1米；点击固定、键盘方向键每次移动1米。地图滚轮以鼠标为中心缩放1—12倍；超过1.05倍后可按住鼠标左键拖动平移，视口限制在全岛范围内。拖动不推进世界时间、不改资源或世界对象；固定观察点保持原位，鼠标预览模式在松开后更新为指针下的新位置。拖动不会误触发点击固定，“全岛”按钮可恢复全图。1平方米是取样步长，不代表精确地形、树木或真实资源普查。林地、灌丛、岸滩的候选描述来自模拟细分区。没有依据新增河流、裂谷或可食植物。

白昼可辨范围默认220米，降雨85米，较强降雨45米，夜间12米；遮挡会继续缩小。每张方向卡按水平±50度采样，斜角对象标为“左/右前方”，只由角差最小的卡主述；相邻卡只保留一句“视野边缘”提示，不复制整段资源描述。距离层按0—10米、10—40米、40米以上分档；射线每5米取样，所以第一个中景样本通常在15米、第一个远景样本在45米，某一层没有可辨差异时可以不写。地形趋势用约10米间隔的粗DEM采样和线性趋势，不从2米差分的小数生成陡崖。没看见不等于没有。

遮挡按具体视线判断：正前方射线被挡，只说明正前方更远处看不清；岸线另检查中心和左右各12度的视线，资源目标也逐个检查从观察点到目标的视线。因此，正前方被挡时，斜前方仍可能看见一段海岸或目标；若那条斜向视线也被地形/树冠挡住，就不描述它。这个规则是简化的二维视线，不是完整三维光照或树木模型。

四个水平卡片是研究者绝对方位。角色文本用面前、右侧、身后、左侧，代表同一观察朝向，并不直接教会角色北在哪；此版本没有求生者的真实转身、定位和记忆模块。太阳描述仅提供可能线索，树冠下不保证能看见太阳。上方给天色/冠层，脚下给地表/岸缘。景物变化来自相同世界状态，不是独立随机编故事。

## 水账

W01初始0.5升、上限1升，降雨每毫米进0.03升；无雨基准每日损失0.02升，再乘clamp(温度/26,0.5,1.5)。W02初始不存在，研究者启用后为0升、容量10升，雨补0.35升/毫米，无雨基准损失0.05升/日。每小时先扣当前存量可承担的损失、再补雨、最后记溢流。地下常流设为0。

界面启用W02是研究者配置，不是玩家凭空完成建造。不含取水、饮水或人体消耗。后台记录累计进水、损失、溢流，可核对水量守恒。

## 资源

木材、纤维、近海鱼池与甲壳类按既有点位预算逐小时补充，到容量停止。木材变干不会增加木材。鱼池补充表示外部迁入或重新可接近，并不是一小时长成鱼。

椰果预算累积到整数后增加；另外按现有果每日2.5%的损耗预算累计到整数扣除，代表落果腐败。不保证给人物持续供给。

山羊：成熟延迟365天、年度招募预算0.24、自然损失率0.10。贝类：365天、0.35、0.15；鸟类：180天、0.32、0.16。均为工程假设，非本岛观测率。采用幼体队列，成年数与幼体数合计不超容量。贝类有外部幼体输入；山羊、鸟需至少2个成年个体才积累招募预算。未建模性别配对、迁徙、季节繁殖和完整食物网。

鸟类仅观察，不可试采；石块和空壳不再生。空壳不是带肉贝类。界面“研究试采”只测试库存扰动：计件每次取1，计重每次取0.5kg；不运行角色工具、动作概率、背包、加工、生理或每日采集额度。它不能替代未来求生者行动裁决。岸边研究试采也受模拟潮位和昼夜限制。

材料湿润指数0—1；降雨每小时加0.5、无雨每小时减0.05，截到范围内。该指数不是实测木材含水率。

同一天、同资源类别的多个幼体成熟事件合并成一条日志，显示成熟总数和最多5个资源点编号；若涉及更多点，补充总地点数。只合并日志显示，不合并或改变资源点库存，研究者仍可按编号回查具体位置。

## 时间与存档

自动模式每秒推进1小时，页面转入后台时暂停。关闭页面不推进；下次载入导出的JSON恢复同一状态。单次推进最多5年。每个访问者拥有独立世界，没有服务器、共享状态、付费模型或密钥。

只有按明确控制推进才会改变世界；鼠标移动和天气预览不消耗时间。存档包含版本、种子、当前小时、资源队列、水账、观察位置和最近100条事件。保存不自动上传GitHub。载入对版本、库存和容量做校验，错误文件不替换当前世界。

## 当前范围

这一版实现的是岛屿观测控制台，不是完整生存游戏。未来接求生者时沿用状态与文本边界，再加入实际行动事件、身体接口、角色记忆和可见性细化。原Python长期引擎作为历史规则参考，不与本浏览器状态互相实时同步。数据配置、自然规则与界面分文件保存，避免两套描述各自漂移。

## 脚下干湿

脚下描述参考此前24小时的模拟降雨，越早的雨影响越小，林区增加少量保湿修正。这个指数只用于区分偏干、微潮、湿润，不是实测土壤含水率，也不是完整水文模型。


## v2 空间与观测函数（本节覆盖旧版38区/14点的数量）

局部场由位置产生：树冠覆盖、灌草密度、石砾比例、落叶覆盖使用不同尺度的平滑格点噪声。先对相邻格点的固定种子值做平滑插值，因此接近位置通常连续变化。它们是有空间关联的设计场，不是现场测量，也不靠每移动一米随机换一句话。

资源影响：每个斑块权重=max(0,1-距离/半径)，局部资源线索=sum(真实剩余库存×权重)。这是可见线索强弱，不是新库存；试采仍扣同一份斑块库存。当前没有精确模拟每一颗果的位置。近地描述允许在资源中心出现，修复旧版小于2米直接消失的问题。

观测=位置场+方向射线+库存+时间天气+条件句组合。六向卡分别包含近处结构、通行条件、遮挡/岸线、可见资源；上方含树冠/天空/太阳，脚下含地面/干湿/散落物和可接近资源。不保证相邻每一米都换句子，文字只在可感知差异足够时变化，避免伪造精度。

白天近岸且无强雨时，岸边方向或脚下可以出现鱼影、礁缝贝类和甲壳类线索；夜晚、强雨或涨潮会降低辨认和接近程度。没有鱼影不等于海里没鱼，看到鱼也不等于必然捕获。资源斑块85米内作为近岸背景、岸线65米内允许粗线索；这都是可校准的模拟尺度。

v2采用丰富资源情景，旧v1存档不兼容，载入将明确拒绝。每个访客仍独立运行，没有共享服务器。新增资源补充预算沿用简化模型，只是丰富场景，不是已校准生态。火、加工、建造、自由配方、季节繁殖和身体系统尚未接到本控制台。

## v3 局部移动雨带

2026-11-07新增。全岛不再同一时刻一起下雨。每次雨事件沿东向西传播，东西岸的到达差约2小时；这只是雨带有效推进的设计时间，不是本岛风速或气象实测。受小岛尺度、云团形态影响的真实移动时间没有资料，本实验允许以后改方向和时长。

函数：到达延迟=2小时×(最东坐标−当地E)/(最东坐标−最西坐标)。当地雨强取背景雨时序向后平移该延迟，再对4个相隔7.5分钟的历史值取平均，以减轻雨带边缘突跳。每个位置完整经历一次事件时，累积雨量与背景事件一致；同一个日历日的当地雨量可能跨日，不再要求当天严格等于背景日表。

雨带前缘灰色表示雨云接近，蓝色深浅表示当地模拟雨强。雨带尾缘也逐渐退出；短雨事件可能出现东岸已经停雨、西岸才下雨，并非每次都会全岛同时有雨。当前雨带是沿南北延展的简化带，不含真实云微物理、地形抬升降雨、随机风向或雷暴。

世界以15分钟子步结算；+1小时/+1天仍会逐步处理。材料按资源斑块所在地雨量变化，W01按岩池位置、W02按营地位置补水；当地雨量×时长才是这步的降水量。观测、地面干湿近似、预报和太阳可见条件均使用观察点雨量。水量的补给、蒸发、溢流账本保持同一套。

点击“下一场雨”会实际推进世界至下一场背景降雨开始前15分钟，不是强行改天气；库存、材料和水源一起推进。接着点+15分钟或自动，每秒推进15模拟分钟，查看蓝灰带移动。关闭网页不推进。

存档标记observation-v3，旧版本会被明确拒绝，防止把旧雨量结算与新规则误作完全一致的复现。气候背景和逐日表仍为资料代理支撑的合成时序，不是真实天气预报。

## v4 方向事实观测（2026-11-07）

这轮不再先写句子再挑方向，而是先生成结构化事实，再由事实投影成文字。顺序是：唯一世界状态→观察点与方向采样→近/中/远景、坡度、岸线、遮挡、资源范围→可见性与重要性筛选→文字。代码在observation.js，算法标识obs-dir-v4；存档格式仍是observation-v3，旧v3档可继续载入。

每张水平卡的半角为50度，四卡在斜角有约10度重叠。近岸或林下斑块按角差归给最近的一张卡；斜角对象可以进入相邻卡的“视野边缘”，但只提一句，不重复细节，也不会同时出现在背向两张卡。这样东北方向的同一丛枯木可以在北、东两卡被说明为同一处，而不是四向各写一遍。

地形趋势沿视线取0、10、20、30、40、50、60米的高程，做线性趋势并检查中段低洼。上坡/下坡分“略有、缓缓、持续、明显/较陡、迅速”几档，但全部是粗DEM插值的保守措辞，不是米级测绘。海岸高程衰减仍会让近岸一段抬高，因此只描述方向和相对变化，不据此宣布陡崖、裂谷或精确坡度。

岸线距离取本卡扇区内最近的水边：中心射线加上左右各12度两条射线的出口距离，取最小；再比较左右出口，说明岸线大致横在正前、向左斜还是向右斜。约90米DEM不能给出米级岸线形状，这个距离是可复核的模拟几何，不是实测岸线宽度。

遮挡规则：沿射线每5米检查地形高程加树冠高度，超过眼高约2.5米且距离至少20米才算遮住；遮挡之后不再描述远景、岸线或海域资源。树冠高度由生物群系和连续冠层场估算，不是逐棵树的三维模型。

近岸资源关联：鱼贝锚点仍只是岸边作业入口，不是鱼的真实坐标。每个含R05/R06/R07的锚点投影到最近岸线，再向海一侧偏移约9米，形成半径12—26米的模拟海域范围；海域范围只引用该锚点原有的同一份库存，不复制鱼贝数量。观察时只选本卡角差最小、未被地形/树冠挡住的一片海域；120米内才谈鱼影，60米内才谈礁缝贝类和甲壳类，看到不等于能抓到。鱼、贝、甲壳类各有自己的库存、潮位和观察机会，不整段捆绑。

观察机会用固定种子、海域编号和3小时时段生成，不使用Math.random；同一位置同一时刻反复观察稳定，移动鼠标或逐米走动不会刷出新鱼影。没有鱼影不会扣库存，库存耗尽后对应线索才消失。

雨势、昼夜、潮位和全向可辨上限在六向卡上方只完整说一次；方向卡只补该方向的实际影响，例如朝海一侧的水声、雨幕压住的水面，或背向一侧的坡面暗影。角色文本仍只给相对方位，不含绝对罗盘、库存数字或全岛地图。

## 本轮观测文字与卡片排版

距离统一写成“约X米处”。水边在10米内时，描述岸缘以湿砂或礁面为主，不再说“脚下很快变湿”，避免把观察点和前方目标混为一谈。退潮时按礁缝可见线索写贝类；涨潮时依据近/远距离和库存等级选择可见的水下线索。库存等级只用于挑选概括性描述，不输出后台数字。相同时间、位置和库存得到相同文字；不靠随机同义词制造变化。六向卡片按文字自然排布，取消固定最小高度以减少空白。
