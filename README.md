# SITP 文本生存 · 岛屿观测台

在线：https://2024-dada.github.io/SITP-text-survival/

当前v3：836个20米细分格、219个资源斑块、米制观察点、六向同步描述、15分钟子步自然演化、约2小时过岛的东向西雨带、丰富资源情景。无需服务器、模型或构建，直接打开index.html即可。

## 代码

data.js为场景配置；model.js管时间与唯一库存；observation.js按位置场、视线、库存与天气生成文字；app.js负责界面；style.css为样式。docs下仅区域、气候、规则三份主题文档。SPEC.md记录范围。

## 边界

岸线和粗高程来自资料；细分格、植被、资源位置和资源增量是明确的设计。1米不是实测精度。近邻点不强求完全不同文字。观察不改变状态，试采才扣库存。v3不兼容v1/v2存档。角色身体、实际行动接口、记忆、火与加工尚未接入这个静态控制台。

## 接手

先阅读本地SITP外层AGENTS.md、agent.md与readme.md，更新当前状态、已知问题和下一步后再交付。代码变更需要同步三篇主题说明与本README；不得将设计数量回写成第一阶段真实调查。原始资料不放公开仓库。
