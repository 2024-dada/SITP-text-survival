# SITP 文本生存 · 岛屿观测台

在线：https://2024-dada.github.io/SITP-text-survival/

当前线上版本：**v3.1（观测算法 obs-dir-v4）**，已同步到 GitHub Pages 与仓库主分支。六向观察先按方向生成坡度、岸线、遮挡和资源事实，再写成文字；岸线与资源目标分别检查视线，避免不同方向复用同一段描述。变化记录会合并同日同类成熟事件，并保留资源点编号。地图滚轮以鼠标位置为中心缩放（1—12倍），“全岛”按钮恢复视图；缩放不改实验状态。836个20米细分格、219个资源斑块、米制观察点、15分钟子步、约2小时东向西局部雨带和丰富资源情景沿用v3。无需服务器、模型或构建，直接打开 `index.html` 即可。

## 代码

data.js为场景配置；model.js管时间与唯一库存；observation.js按位置场、方向采样、视线、库存与天气生成文字；app.js负责界面；style.css为样式。docs下仅区域、气候、规则三份主题文档。SPEC.md记录范围。

观测流程是“世界状态→位置/方向采样→结构化事实→可见性与重要性筛选→文字”，不是先写句子再挑方向。每个斑块只由角差最小的方向卡主述；斜角对象可在相邻卡提一句“视野边缘”，不复制整段。海域斑块由岸边锚点向海投影得到，只引用原锚点的同一份库存。

## 边界

岸线和粗高程来自资料；细分格、植被、资源位置和资源增量是明确的设计。1米不是实测精度。近邻点不强求完全不同文字。观察不改变状态，试采才扣库存。v3存档继续可用；v1/v2存档仍被拒绝。角色身体、实际行动接口、记忆、火与加工尚未接入这个静态控制台。

## 接手

先阅读本地SITP外层AGENTS.md与readme.md，更新当前状态、已知问题和下一步后再交付。代码变更需要同步三篇主题说明与本README；不得将设计数量回写成第一阶段真实调查。原始资料不放公开仓库。本轮六向观测复核说明、参数边界、六点证据与此前版本检查结果在 `docs/复核说明_六向观测_20261107.md`。方向观测版本曾通过69项观测检查、16项浏览器检查；这16项未覆盖本轮新增的拖拽平移，本轮未运行测试。GitHub Pages 此前已核对显示 v3.1 与 `obs-dir-v4`。

地图交互：鼠标放在地图上滚轮缩放，以指针为中心，范围1—12倍；放大超过1.05倍后可按住鼠标左键拖动平移，地图边缘限制在全岛范围内；右上角“全岛”恢复视图。拖动和缩放不推进时间、不改库存；固定观察点保持原位，鼠标预览模式则在松开后显示指针下的新位置。拖动不触发点击固定，Ctrl+滚轮保留浏览器缩放。
