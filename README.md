# SITP-文本生存

欧罗路亚岛｜第二阶段静态观测控制台。

- 地图固定，鼠标悬停预览、点击固定；方向键以1米模拟步长移动观察点。
- 六向景象同时显示，小时天气、雨水、潮位、材料及资源自然变化。
- 研究者试采、集雨器设置、时间快进和存档，全部在浏览器本地计算。
- 无服务器、无模型API、无人物身体计算。多人访问互相独立。

## 在线与本地

GitHub Pages设置：main分支，根目录。预期地址：https://2024-dada.github.io/SITP-text-survival/ （以实际发布状态为准）。本地可直接打开index.html，或在本目录运行Python的http.server；没有构建依赖。

## 文件

index.html是页面；style.css是外观；app.js是交互；model.js是自然规则和观测；data.js是唯一场景配置。docs中仅三篇主题文本：[区域](docs/区域.md)、[气候](docs/气候.md)、[规则](docs/规则.md)。SPEC.md记录本轮实现边界。

## 证据与设定

OSM岸线、Lakeba区域温雨、GLO90粗高程是资料参考。38个子区、14个资源锚点、植物分布、小时天气和生态速率是明确的模拟设定。1米步长不代表1米实测精度；预报界面不是现实预报。
