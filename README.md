# SITP 文本生存 · 岛屿观测台

在线：https://2024-dada.github.io/SITP-text-survival/

本地工作版v3.1（观测算法obs-dir-v4；当前正在准备发布），线上仍为v3，提交cbcbe92。六向观测先按方向生成坡度、岸线、遮挡和资源事实，再写文字；岸线和资源目标按各自视线检查。新增同日同类成熟事件的合并日志，保留资源点编号，避免变化记录被重复小条目淹没。地图滚轮以鼠标为中心缩放（1—12倍），全岛按钮恢复视图，不改实验状态。836个20米细分格、219个资源斑块、米制观察点、15分钟子步、约2小时东向西局部雨带和丰富资源情景沿用v3。无需服务器、模型或构建，直接打开index.html即可。

## 代码

data.js为场景配置；model.js管时间与唯一库存；observation.js按位置场、方向采样、视线、库存与天气生成文字；app.js负责界面；style.css为样式。docs下仅区域、气候、规则三份主题文档。SPEC.md记录范围。

观测流程是“世界状态→位置/方向采样→结构化事实→可见性与重要性筛选→文字”，不是先写句子再挑方向。每个斑块只由角差最小的方向卡主述；斜角对象可在相邻卡提一句“视野边缘”，不复制整段。海域斑块由岸边锚点向海投影得到，只引用原锚点的同一份库存。

## 边界

岸线和粗高程来自资料；细分格、植被、资源位置和资源增量是明确的设计。1米不是实测精度。近邻点不强求完全不同文字。观察不改变状态，试采才扣库存。v3存档继续可用；v1/v2存档仍被拒绝。角色身体、实际行动接口、记忆、火与加工尚未接入这个静态控制台。

## 接手

先阅读本地SITP外层AGENTS.md与readme.md，更新当前状态、已知问题和下一步后再交付。代码变更需要同步三篇主题说明与本README；不得将设计数量回写成第一阶段真实调查。原始资料不放公开仓库。本轮六向观测复核说明、参数边界、六点证据与测试结果在 `docs/复核说明_六向观测_20261107.md`。

地图交互：鼠标放在地图上滚轮缩放，以指针为中心，范围1—12倍；右上角“全岛”恢复视图。缩放只改视口，不改实验时间、观察点或库存，Ctrl+滚轮保留浏览器缩放。
