# SITP 文本生存 · 岛屿观测台

在线：https://2024-dada.github.io/SITP-text-survival/

当前页面版本：**v3.3.2（观测算法 obs-dir-v4）**。每个雨日的开始时刻按日期和实验种子变化，按15分钟一档生成；雨日、日雨量、两小时雨程与东向西约2小时局部雨带保留。六向方向观测、鼠标中心缩放/拖动、836个20米细分格、219个资源地带和15分钟子步沿用上一版。v3.3新增五类生物的幼体—亚成体—成体队列、日繁殖与阶段死亡、五个生态食源池、季节/降雨驱动的恢复、食物压力反馈，以及动态食源承载量和独立硬上限。研究者账本会显示种群阶段、食源存量/恢复/取食、推算承载量和硬上限。所有缺少Olorua实测依据的种群与生态参数及逐场降雨时刻均为标注过的模拟假设；这不是完整食物网或野外承载力结论。网页纯静态，无服务器或模型API，直接打开 `index.html` 即可。

## 代码

data.js为场景配置；model.js管时间与唯一库存；observation.js按位置场、方向采样、视线、库存与天气生成文字；app.js负责界面；style.css为样式。docs下仅区域、气候、规则三份主题文档。SPEC.md记录范围。

观测流程是“世界状态→位置/方向采样→结构化事实→可见性与重要性筛选→文字”，不是先写句子再挑方向。每个斑块只由角差最小的方向卡主述；斜角对象可在相邻卡提一句“视野边缘”，不复制整段。海域斑块由岸边锚点向海投影得到，只引用原锚点的同一份库存。

近岸的方向卡会根据到礁面的距离、潮位和该片模拟库存等级描述可见线索；同一条件下保持稳定，措辞变化对应不同位置或观测条件，不靠随机同义句制造差异。库存等级只用于选择概括性文本，不向角色暴露后台精确数量。六张卡随各自文字自然排布，不设置人为最小高度来填空。方向卡、时段天气卡、水量卡、附近资源卡和生态卡可点击打开大字预览；滚轮围绕预览卡片中心缩放，点击卡片外关闭，预览期间时间仍会继续演化。

## 边界

岸线和粗高程来自资料；细分格、植被、资源位置、种群与食源均是模拟设定。生物生态只反馈岛屿状态，不计算人物身体。海陆食源是独立生态折算池，不等同于角色可采集库存；动态承载量不同于程序硬上限。模型没有物种级鸟/鱼、捕食、疾病、迁徙、性别配对或完整食物网。1米不是实测精度。近邻点不强求完全不同文字。观察不改变状态，试采才扣库存。旧v3存档迁移时保留当前时间/库存/种群并初始化新的食源基线；新开局使用v3.3生态设定。v1/v2存档仍被拒绝。角色身体、实际行动接口、记忆、火与加工尚未接入这个静态控制台。

## 接手

先阅读本地SITP外层AGENTS.md与readme.md，更新当前状态、已知问题和下一步后再交付。代码变更需要同步主题说明与本README；不得将设计数量回写成第一阶段真实调查。原始资料不放公开仓库。生态参数和逐场降雨时刻均为明确标注的模拟设定。v3存档迁移到observation-v4并初始化生态基线。v3.3.2待发布；`node --check model.js` 与 `git diff --check` 通过，未运行行为测试或浏览器交互测试。

地图交互：鼠标放在地图上滚轮缩放，以指针为中心，范围1—12倍；放大超过1.05倍后可按住鼠标左键拖动平移，地图边缘限制在全岛范围内；右上角“全岛”恢复视图。拖动和缩放不推进时间、不改库存；固定观察点保持原位，鼠标预览模式则在松开后显示指针下的新位置。拖动不触发点击固定，Ctrl+滚轮保留浏览器缩放。
